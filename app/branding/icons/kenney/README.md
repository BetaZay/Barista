Only non-brand interface glyphs are included. Exporter metadata, unused groups,
and undeclared Inkscape attributes were removed; original path geometry is
preserved. `copy.svg` composes two scaled tablet glyphs with an occlusion clip.
`../dropdown.svg` rotates the caret-right glyph downward and applies the café tint.
The external/open glyph represents opening the log folder. All icons are tinted
and rendered at a common size by Barista; no icon font or download is needed at
runtime. The Barista cup logo and pairing protocol symbols are separate branding
and content, not part of this icon pack.
